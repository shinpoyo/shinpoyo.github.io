# 広告（Google AdSense）の導入手順

2026-10-11 決定：**Google AdSense** を shinpoyo.com 単位で申し込み、全プロジェクトで使う。

## 広告の場所

| サイト | 場所 | 状態 |
|---|---|---|
| 個人サイト（このリポジトリ） | トップ・作品一覧・マシマシ打／けしカスの紹介ページの下部 | 仕組みあり（`ads.js` に ID を入れると表示） |
| 個人サイト | もぐもぐカメラの紹介ページ | **置かない**（子ども向けの内容のため） |
| マシマシ打 | 食券購入の下部・完飲番付・常連カード | 仕組みあり（mashimashida の Actions 変数で ID を設定すると表示） |
| マシマシ打 | 結果画面の近く | **置かない**。結果はタイピング修行のポップアップ内に出るため（AdSense はポップアップ内の広告を禁止）。結果から `Enter` で移る完飲番付の広告で代わりにする |
| マシマシ打 | プレイ中 | 置かない（誤クリック・プレイの邪魔） |

## 準備済み

- プライバシーポリシー：`/privacy/`（広告 Cookie・オプトアウト・外部送信の一覧・お問い合わせ）。全ページのフッターからリンク
- 広告枠：ID が未設定なら表示も外部読み込みもしない（いまは広告なし）

## あなたの作業

1. **申し込み**：https://adsense.google.com/ → Google アカウントでログイン → サイトに `shinpoyo.com` を入力 → 国「日本」→ 支払い先住所などを登録
2. **サイトの確認**：確認用メタタグと `ads.txt` は設置済み（サイト運営者 ID `pub-3053925393924248`）。AdSense の確認方法で「メタタグ」または「ads.txt スニペット」を選んで「確認」
3. **審査**：AdSense で「審査をリクエスト」。数日〜数週間。落ちた場合は理由を Claude に伝える（よくある理由：コンテンツが少ない → 作品ページの説明文を充実させる）
4. **合格後**：AdSense → 広告 → 広告ユニットごと → **ディスプレイ広告** を1つ作成（レスポンシブ）→ **広告ユニット ID**（数字10桁）を Claude に伝える
   - 個人サイト：Claude が `ads.js` に ID を入れる
   - マシマシ打：mashimashida の Settings → Secrets and variables → Actions → **Variables** に `ADSENSE_CLIENT`（ca-pub-…）と `ADSENSE_SLOT`（10桁）を追加 → Actions「Deploy to GitHub Pages」を再実行（Claude もやり方を案内できる）
5. **同意メッセージ（任意だが推奨）**：AdSense → プライバシーとメッセージ → **欧州の規制**のメッセージを作成・公開。EU・英国などから見られた場合に必要（Google 認定の同意管理を無料で使える）

## 注意

- 自分で広告をクリックしない・クリックを頼まない（アカウント停止の原因）
- AI 生成画像の利用規約（商用利用・表示義務）を確認しておく（mashimashida の `docs/compliance.md` の C）
- 収入が出たら確定申告の対象になる場合がある（雑所得など。年間の所得額によって要否が変わる）

## 審査結果と対応

### 2026-10-25 確認：不承認（要確認）

- 理由：**有用性の低いコンテンツ**（「サイトが独自の価値を提供し、ウェブ上で一貫したプレゼンスを確立し、〜ユーザーの関心を集めている必要がある」）
- Google が挙げた確認点：信頼できる高品質な情報・ツール・サービス／継続的なキュレーションと構造のメンテナンス／ユーザーの純粋な関心
- 対応：[品質チェック](quality-audit.md) の順に直す。Search Console の確認は [search-console.md](search-console.md)
- 再審査は、直したあと、新しい内容が検索に登録されてから（すぐに何度も送り直さない）
