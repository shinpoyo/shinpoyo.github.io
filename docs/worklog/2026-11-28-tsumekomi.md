# 2026-11-28 つめこみ戦記を載せる

## 依頼
Bag リポジトリのゲームを、ほかのゲームと同じ形（紹介ページ＋埋め込み、作品一覧、サイトマップは紹介ページだけ）で載せたい（shinji）。
「パブリックにしないとダメ？」→ しなくてよい。名前は候補から「つめこみ戦記」を選んでもらった。

## やったこと
- **ゲーム本体** `/tsumekomi/`：Bag リポジトリ（非公開）を `npx vite build --base=/tsumekomi/` でビルドした出力をそのまま置いた。SMUDGE 体験版と同じ方法。更新手順は Bag リポジトリの `docs/publish.md`
  - `public/assets/aistudio/`（AI Studio の資料・スクリーンショット）はゲームで使っておらず、公開しないので外した
- **紹介ページ** `/works/tsumekomi/`（`_src/37-tsumekomi.html`）：遊び方・操作・アイテム・★シナジー・進化合成・カバン拡張・30 秒の疲労・敵の傾向・コツ・画面・FAQ。ゲームを埋め込み
  - `new_until: 2026-12-12` で 2 週間、一覧の先頭に「新作」で並ぶ
  - 広告は置く（子ども向けではないので、ほかの作品と同じ）
- トップ（作品・お知らせ）、作品一覧（遊び方で選ぶ・ストラテジー・比較表）に追加。ストラテジーの説明を「守るゲーム」→「戦うゲーム」に
- 画像：カード `assets/img/tsumekomi.jpg`（タイトル・準備・戦闘を 1280×720 に並べた）と、紹介ページ用の 3 枚。Playwright で 430×900 で撮った
- 遊ばれた回数の ID は `tsumekomi`（`game_url:` から自動）

## 確かめたこと
- `python3 _tools/build.py` で書き出し。sitemap には紹介ページだけが入り、`/tsumekomi/` は入らない
- Playwright（幅 390px）で紹介ページ・作品一覧・トップが横にはみ出さないこと
- 紹介ページで「ここを押して遊ぶ」→ 埋め込みのゲームが開き、「ゲーム開始」で準備画面に進むこと。コンソールエラーなし
