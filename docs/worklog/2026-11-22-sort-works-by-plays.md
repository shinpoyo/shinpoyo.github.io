# 2026-11-22 作品一覧を遊ばれた回数の順に並べる

## 依頼
「アクセスランキング順にゲームを並べるとかできる？」（shinji）。サイトにはアクセス解析が入っていなかったので、数え方を3案出し、**案1：「遊ぶ」が押された回数を自前で数える** に決まった。

## しくみ
```
shinpoyo.com（assets/plays.js）          api.shinpoyo.com（mashimashida の worker/）
  「遊ぶ」を押す・埋め込みのゲームを触る
    ── POST /v1/plays {"game":"keshikasu"} ──▶ 1日・1作品・1人（IP のハッシュ）に1回だけ数える
GitHub Actions（毎日 3:40 JST）
    ── GET /v1/plays?days=30 ────────────────▶ 直近30日の作品ごとの人数
    _data/plays.json に保存 → build.py で並べ替え → 並びが変わったときだけ main にコミット
```
サーバー側は shinpoyo/mashimashida の同名ブランチ（`worker/` に API と D1 の `plays` テーブル）。

## やったこと
- `assets/plays.js`：「遊ぶ」リンク（`/keshikasu/` など）のクリック（中ボタンも）と、作品ページの埋め込みゲームを触ったとき（ページのフォーカスが iframe に移ったとき）に `navigator.sendBeacon` で作品 ID を送る。同じブラウザ・同じ日の2回目は送らない
- `_tools/build.py`
  - 全ページの末尾で `plays.js` を読み込む。遊ぶ URL → 作品 ID の対応表は作品ページの `game_url` から作る
  - `data-sort="plays"` の `<ul>`・`<tbody>` の中身を、`_data/plays.json` の回数の多い順に並べ替える（同数・データなしは書いた順のまま）
  - `<!-- PLAYS_NOTE -->` に「直近30日に遊ばれた回数の多い順に並べています。」（データがなければ消える）
  - 作品ページ末尾の「ほかの作品」も回数の順に
- 並べ替える場所：トップの「作品」、作品一覧のジャンルごとの一覧と「作品の比較」の表。「遊び方で選ぶ」の表は1行に複数の作品があるのでそのまま
- `.github/workflows/sort-works-by-plays.yml`：毎日回数を取り、並びが変わったときだけ `_data/plays.json` と HTML をコミット。API に届かない日は何もしない
- プライバシーポリシーに「作品の遊ばれた回数」を追加し、外部送信の表の Cloudflare の行に追記。改定日を更新

## 確認
- `_data/plays.json` に仮の数字を入れて書き出し、トップ・作品一覧・「ほかの作品」が多い順、同数は元の順になることを確認（確認後に削除。データがない今は並びは変わらない）
- Playwright（手元のファイルを `page.route` で読ませる）で、トップの「遊ぶ」を押すと `{"game":"keshikasu"}` が `text/plain` で送られる・同じ日の2回目は送られない・オセロの作品ページで埋め込みのゲームを押すと `reversi-with-sis` が送られる・ページエラーなし
- サーバー側はローカルの Worker + D1 で確認（mashimashida の作業履歴）

## 残っていること
- サイトから直接ではなく、検索や共有から直接ゲームの URL に来た人は数えない（各ゲームに手を入れる必要があるため）
- 新しく載せた作品は回数が少ないので下に行く。必要なら「新作は一定期間先頭」にできる
