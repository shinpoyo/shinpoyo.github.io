# 2026-11-27 作品ページを「ゲームが先、説明が下」の形にする

## 依頼
人気のブラウザゲームサイトのやり方を聞かれ、Sudoku 247 のスマホの画面（ヘッダーのすぐ下に画面いっぱいのゲームと「Press here to play!」、その下に遊び方の長い文章）を見て、「そのレイアウト真似しようよ」（shinji）。

## やったこと
- `_tools/build.py` の `game_first`：作品ページに埋め込みのゲーム（`<div class="game-embed">`）があれば、パンくず・見出しより上、ページの一番上に移す。「下のゲームを、このページでそのまま遊べます。」の一文は消す
- ゲームはすぐには読み込まず、作品の画像をぼかした背景に、画像・▶・「ここを押して遊ぶ」を重ねた表紙を出す。押したら iframe を読み込む（`assets/game-embed.js`）
  - ページを開いただけでゲームを読み込まないので軽い。スマホでページを下に読み進めるとき、指がゲームに取られない
  - 表紙はゲームへの普通のリンクなので、JavaScript が動かなくても遊べ、遊ぶカウンター（plays.js）にも数えられる
- ゲームの高さは、画面の高さからヘッダーを引いた分（最小 520px・最大 860px）
- けしカスもゲームを埋め込む形にした（スマホの縦画面でも遊べることを確かめた）。マシマシ打（キーボードが必要）・もぐもぐカメラ（カメラの許可が要る）はボタンのまま

## 対象
ねーちゃんとオセロ・けしカス・はるしねーちゃん・Bullet Reflector・アルケマージ・SMUDGE
