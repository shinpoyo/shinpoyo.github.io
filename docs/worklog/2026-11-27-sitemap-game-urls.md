# 2026-11-27 サイトマップからゲーム本体の URL を外す

## 依頼
「ゲームだけの画面を無くすのを進めよう」（shinji）。サイトマップの判断カードで「外して紹介ページだけに」を選んだもの

## 理由
- AdSense の不承認理由は「有用性の低いコンテンツ」。ゲーム本体のページは JavaScript で描くので、検索エンジンからは本文がほぼ空に見える（[quality-audit.md](../quality-audit.md)）
- 紹介ページにゲームを埋め込んだ（PR #18）ので、検索の入口は紹介ページで足りる

## やったこと
- `_tools/build.py`：サイトマップにゲーム本体の URL（8本）を書かないようにした。30件 → 22件
- `docs/quality-audit.md` の 7 を済みにした

## 残っていること
- サイトマップから外しても、リンクをたどって検索に載ることはある。完全に出さないなら、各ゲームのリポジトリで `noindex` か、紹介ページへの `canonical` を入れる（未着手）
