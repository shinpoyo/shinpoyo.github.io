# AdSense で収益を上げているサイトの特徴 20（2026-10-27 調査）

shinpoyo.com に反映するため、Google の広告で運営している人気サイトを観察し、共通する特徴を 20 個にまとめた。

## 調べ方と限界

- **収益額は外から分からない**。そこで「Google の広告を実際に配信していて、長く続いている人気サイト」を対象にした。ゲーム・ツール・タイピングなど、shinpoyo.com に近いジャンルを選んだ
- 各サイトのトップを PC（1366px）とスマホ（390px）で実際に表示し、ページの作り（文章量・リンク数・見出し）、広告の位置と大きさ、目立つ要素（ランキング・新着・遊び方など）を記録した
- あわせて、Google の公式の基準（[AdSense の利用条件](https://support.google.com/adsense/answer/9724)、[有用なコンテンツの作り方](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)、[パブリッシャー ポリシー](https://support.google.com/adsense/answer/9335564)）を確認した
- 観察は 1 日だけ・トップページ中心。広告の数や位置は、閲覧者や時間で変わる

## 特徴 20

各項目の「反映」は、今回やること／広告の承認後にやること／やらないことのどれかを書いた。

### A. 開いてすぐ遊べる・使える

1. **最初の画面で、すぐ遊べる（使える）**
   寿司打・Solitr・Sudoku 247・TypingTest は、開いた瞬間に「Play」か本体がある。説明を読ませてから遊ばせない。
   → 反映（今回）：作品ページの上部で、ゲームをそのまま遊べるようにする（埋め込みを、ねーちゃんとオセロ以外にも広げる）。埋め込みに向かない PC 向けの作品は、大きな「遊ぶ」ボタンを上に置く

2. **ゲームの下に、遊び方・攻略・FAQ の文章がしっかりある**
   Sudoku 247 は、ゲームの下に約 1.7 万字の解説がある。「遊ぶ」と「読む」が 1 ページにそろっている。
   → 反映：すでに各作品ページにある（遊び方・コツ・FAQ）。埋め込みと組み合わせて、1 ページにそろえる

3. **一言で何のサイトか分かる**
   「楽しくタイピング練習ができる『マイタイピング』」「Play Free Sudoku Games Online」のように、タイトルと冒頭の一文で目的が分かる。
   → 反映（今回）：トップのタイトルと説明を「無料で遊べるブラウザゲーム」が伝わる形にする

### B. 迷わず、回遊できる

4. **作品がジャンル別に並んでいる（ポータル型）**
   keisan・Cool Math Games はカテゴリで整理。寿司打も「タイピング・脳トレ・ミニゲーム」と並べている。
   → 反映（今回）：作品一覧をジャンル別に整理する

5. **ほかの作品・関連ページへのリンクが、どのページにもある**
   マイタイピングはトップだけでリンク約 160 本、Cool Math Games は約 270 本。1 つ遊んだら、次の 1 つに進める。
   → 反映（今回）：各作品ページの下に「ほかの作品」を自動で表示する

6. **おすすめ・人気の入口がある**
   マイタイピング・keisan・Cool Math Games はランキングや人気を出している。
   → 反映（今回）：アクセス数のデータはまだないので「人気」とは書かない。代わりに「はじめての人におすすめ」を、作者のおすすめとして明記して置く

7. **パンくずと、分かりやすいメニュー**
   どのサイトも、いまどこにいるかが分かる。
   → 反映：すでにある（パンくず・構造化データ）

### C. 何度も来る理由がある

8. **毎日・毎週の要素がある**
   マイタイピングの「今週のタイピング」は毎週更新される。
   → 反映（今回）：はるしねーちゃんの「今日の7問」など、毎日遊べる要素を、トップでまとめて見せる

9. **記録・ランキング・自分の成長が残る**
   ランキング、自己ベスト、図鑑など。
   → 反映：作品にすでにある（マシマシ打の完飲番付、はるしねーちゃんの嘘図鑑、けしカスの図鑑）。作品ページとトップで見せる

10. **更新していることが見える**
    寿司打はメニューに「更新」、マイタイピングは「新着」。
    → 反映（今回）：各作品ページに「最終更新」の日付を出す。トップのお知らせは続ける

11. **共有ボタンがある**
    寿司打は X への投稿ボタン、Nonograms も共有がある。
    → 反映（今回）：記事にしかなかった共有リンクを、作品ページにも付ける

12. **更新を追いかけられる**
    ポータル型のサイトは、新着を追う手段がある。
    → 反映（今回）：記事とお知らせのフィード（Atom）を用意する

### D. 信頼できる

13. **誰が、どうやって作ったかが分かる**
    Google の基準でも「Who・How・Why」が明確なことが大事とされる。AI を使ったなら、その開示も勧められている。
    → 反映（今回）：作品ページに「作った人」を表示し、運営者ページ（About）へつなぐ。AI の利用は About と作品ページに書いてある

14. **運営者・問い合わせ・プライバシー・利用上の注意がある**
    寿司打は「ご利用上の注意」まで置いている。
    → 反映：すでにある（About・お問い合わせ・プライバシーポリシー）

15. **独自のコンテンツ（自分で作ったもの）**
    AdSense の条件は「自分のコンテンツで、質が高く、独自で、人を集めること」。どのサイトも、そこにしかない道具やゲームが中心。
    → 反映：shinpoyo.com の強み。作品はすべて自作

16. **作り手の体験が見える**
    Google の基準でも「実際に使った・体験した」ことが評価される。
    → 反映：すでに追加した（作ったきっかけ、ねーちゃんとオセロの実話）

### E. 広告の置き方

17. **広告の場所が決まっている（ヘッダーの下・コンテンツの間・横）**
    keisan はヘッダー下の横長、寿司打と Solitr はゲームの横に縦長、マイタイピングは見出しの下とコンテンツの間。
    → 反映（今回）：広告枠の場所だけを決めておく（承認されるまでは何も表示しない）。作品ページはゲームの下の文章の間と最後、記事は本文の途中と最後

18. **広告はゲームから離して、「広告」と分かるようにする**
    Solitr も TypingTest も、広告はゲームの外。Google のポリシーでも、ゲームの近くの広告は誤クリックの原因として禁止。
    → 反映（今回）：広告枠はゲームから十分離した場所にだけ置く。「広告」の表示は付け済み

19. **スマホでは、コンテンツの間に広告がはさまる**
    マイタイピングはスマホで縦に長く、広告が約 2,500px ごとにある。
    → 反映（承認後）：自動広告の量を見ながら調整する。いまは枠の場所を決めるだけ

20. **Cookie の同意（ヨーロッパなど向け）**
    keisan は Cookie の同意バナーを出している。Google は、ヨーロッパなどの利用者に広告を出すとき、同意の仕組みを求めている。
    → 反映（承認後）：AdSense の「プライバシーとメッセージ」で同意メッセージを設定する（[adsense.md](adsense.md) の手順 5）

## 反映しないこと

- **「人気」「ランキング」を作ること**：アクセス数のデータがないため。データなしで「人気」と書くと、事実と違ってしまう
- **記事を大量に増やすこと**：Google の基準で、検索のための量産は低評価。サイトの中心はゲームなので、作品ページを濃くするほうを優先する
- **サイト内検索**：作品が 6 本なので、いまは不要。増えたら検討する
