ローマ字入力で迷いやすい文字の打ち方 — 「ん」「っ」「ゃ」からカタカナ語まで

公開日：2026.10.27　／　書いた人：shinpoyo

ローマ字入力は「か＝ka」のように規則どおりに打てばよいのですが、「ん」や小さい文字、カタカナ語の音になると、急に指が止まります。タイピングゲーム「マシマシ打」でいちばん多いつまずきも、「ニンニク」を ninniku と打って「にんいく」にしてしまうことです。この記事では、迷いやすい文字の打ち方を整理し、実際に打って確かめられるツールを付けました。

このページは、以前の2本の記事「「ニンニク」が「にんいく」になる理由」と「小さい「っ」「ゃ」やカタカナ語はどう打つ？」を1本にまとめ直したものです。

打って確かめる（確認ツール）

2つの欄があります。どちらも、入力した内容はこのページの中だけで処理され、どこにも送られません。スマホでは、英字のキーボードに切り替えてから打ってください。

ローマ字 → かな：どこで区切られるかを見る

例：

—

    かな → ローマ字：言葉の打ち方を調べて、打ってみる

    例：

    いちばん短い打ち方：—

    「かな → ローマ字」の判定は、マシマシ打の入力判定と同じ表と規則を使っています。日本語入力（IME）によっては、ここにない打ち方が通ることもあります。

    「ん」の打ち方 — n 1回でいいとき、nn が必要なとき

    なぜ「にんいく」になるのか

    ローマ字入力では、n のあとに母音（a i u e o）が来ると「な・に・ぬ・ね・の」になります。そのため、n 1回だけでは、それが「ん」なのか「な行」の始まりなのか、次の文字を見るまで決まりません。

    ninniku を前から順に読んでいくと、次のように区切られます（上のツールに ninniku と入れると、同じ区切りが見られます）。

    入力なる文字
    niに
    nnん
    iい
    kuく

    2つ目と3つ目の n が組になって「ん」になり、残った i が単独で「い」になってしまうわけです。「ニンニク」と出したいなら、「ん」のあとにもう一度「に」を打つ必要があるので、ninnniku（n が3つ）になります。

    見分け方

    多くの日本語入力（IME）では、「ん」の次の文字で決まります。

    「ん」の次の文字「ん」の打ち方例
    あ行（母音）nn が必要げんいん → genninn
    な行nn が必要こんにちは → konnnitiha
    や行・ゃゅょnn が必要こんや → konnya
    それ以外の子音n 1回で OKさんぽ → sanpo
    言葉の最後nn が確実ラーメン → ra-menn

    言葉の最後の「ん」は、IME によっては n 1回でも変換時に「ん」になりますが、次の文字を続けて打つと別の文字とくっつくことがあります。迷ったら nn と覚えておくと安全です。xn でも「ん」になります。

    間違えやすい言葉

    言葉よくある打ち間違い正しい打ち方の例
    ニンニクninniku（にんいく）ninnniku
    こんにちはkonnitiha（こんいちは）konnnitiha
    きんようびkinyoubi（きにょうび）kinnyoubi
    げんいんgenin（げにん）genninn
    せんえんsenen（せねん）sennenn

    広告

    小さい文字だけを打つ

    「ぁ」「ゃ」のような小さい文字は、ふつうは「しゃ＝sya」のように前の文字とまとめて打ちます。小さい文字だけを打ちたいときは、先頭に x か l を付けます。どちらでも同じです。

    文字打ち方
    ぁ ぃ ぅ ぇ ぉxa xi xu xe xo（la なども可）
    ゃ ゅ ょxya xyu xyo
    っxtu（ltu・xtsu も可）
    ゎxwa
    ヵ ヶxka xke

    この打ち方を覚えておくと、どんな組み合わせの音でも「前の文字＋小さい文字」に分けて打てるので、困ったときの逃げ道になります。たとえば「しゃ」は sixya でも打てます（打鍵は増えますが、止まるよりは速いです）。

    小さい「っ」の打ち方

    「きって」「ざっし」のように、「っ」のあとに子音で始まる文字が続くときは、その子音を2回打ちます。

    • きって … kitte
    • ざっし … zassi（zasshi も可）
    • まっちゃ … maccha（mattya も可）

    ただし、子音を2回打つ方法が使えない場面があります。

    • 言葉の終わりの「っ」：「あっ」「えっ」のように後ろに何も続かないときは、a xtu のように単独で打ちます。
    • 次が母音や「な行」のとき：nn は「ん」になるので、「っな」を nna とは打てません。この場合も xtu を使います。

    打ち方が何通りもある文字

    同じ文字でも、打ち方が何通りかあるものがあります。どれで打っても同じ文字になります。

    文字短い打ち方ほかの打ち方
    しsishi ci
    ちtichi
    つtutsu
    ふhufu
    じziji
    しゃsyasha
    ちゃtyacha cya
    じゃjazya jya

    打つキーの数は、短い打ち方のほうが少なくなります。一方で、shi chi tsu のようなヘボン式は、英語の綴りやローマ字の看板と同じなので覚えやすい、という人もいます。どちらが正しいということはないので、自分が迷わない方を選んでください。

    ほかに、つまずきやすいのが次の3つです。

    • を … wo（o では「お」になります）
    • ぢ・づ … di du（「はなぢ」「つづく」など）
    • ー（のばす棒） … 数字の 0 の右にある - キー

    カタカナ語の音

    外来語に出てくる「ファ」「ティ」のような音にも、まとめて打てる書き方が用意されています。

    音打ち方例
    ふぁ ふぃ ふぇ ふぉfa fi fe foファイル、フォント
    てぃ でぃthi dhiパーティー、ディスク
    しぇ ちぇ じぇshe che jeシェア、チェック、ジェット
    うぃ うぇwi weウィンドウ、ウェブ
    ゔvuヴァイオリン（va で「ゔぁ」）

    ti は「ち」になるので、「ティ」を打つときは thi です。「ディ」も di だと「ぢ」になるので dhi を使います。ツールで pa-ti- と pa-thi- を比べると、違いがすぐ分かります。

    表にない音や、使っている日本語入力でうまく出ないときは、小さい文字を単独で打つ方法で「て＋ぃ（te xi）」のように分ければ、どの環境でも入力できます。

    マシマシ打のコールで見てみる

    マシマシ打では、店主の「ニンニク入れますか？」に、トッピングのコールをローマ字で答えます。出てくる言葉はそれほど多くありませんが、この記事の「迷いやすい文字」がちょうど詰まっています。ゲームの判定と同じ規則で数えると、次のようになります。

    コールいちばん短い打ち方気をつけるところ
    ニンニクninnniku（8 打）「ん」の次が「に」なので nn が必要。n が3つ続く
    ゼンマシzenmasi（7 打）「ん」の次が「ま」なので n 1回でいい
    チョモランマtyomoranma（10 打）「ちょ」は tyo cho cyo のどれでも。「ん」は n 1回でいい
    マシマシマシmasimasimasi（12 打）「し」を shi で打つと 15 打。「マシ」が増えるほど差が開く

    同じ「ん」でも、「ニンニク」は nn、「ゼンマシ」「チョモランマ」は n 1回で進めます。ゲームでは、どちらの言葉でも nn と打てば通るので、慣れないうちは nn に統一するのがおすすめです。速さを詰めたくなったら、「し」を si にするのと、「ん」の n 1回を使い分けるのが、打鍵数を減らすいちばんの近道になります。

    マシマシ打の判定は、実際の日本語入力と同じふるまいになるように自動テストで確かめています。作ったときの話は「マシマシ打ができるまで」にまとめました。

    迷わないためのコツ

    • 「ん」はいつも nn で打つ：慣れないうちは、次の文字に関係なく nn と打つ癖をつけると、打ち間違いがなくなります。打鍵数は少し増えますが、打ち直すより速くなります。
    • 打ち方は1つに決める：「し」を si と shi で混ぜていると、毎回どちらにするか迷う分だけ遅くなります。普段から1つに決めておきましょう。
    • 困ったら分けて打つ：x を使った小さい文字の打ち方を1つ覚えておけば、知らない組み合わせでも止まらずに済みます。
    • 画面のかなを見る：打ち終わったあとではなく、打っている途中の表示を見ると、どこで区切られたかがすぐ分かります。分からなくなったら、この記事のツールに打ち込んでみてください。

    コールで練習：マシマシ打は、表示されたカタカナのコールをローマ字で即答するタイピングゲームです。「ニンニク」が何度も出てくるので nn の練習にちょうどよく、画面には打つべきローマ字も表示されます。
