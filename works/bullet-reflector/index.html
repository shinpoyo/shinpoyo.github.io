Bullet Reflector（バレット・リフレクター）

作った人：shinpoyo　／　ゲームの最終更新：2026.10.16

下のゲームを、このページでそのまま遊べます。

PC では、ゲームを一度クリックするとキーボードで操作できます ／ 🔊 音が出ます。音量にご注意くださいゲームだけを大きい画面で遊ぶ ›

敵の弾を、ジャストのタイミングで跳ね返すアクションゲームです。ビリヤードのような物理演算で弾が壁に跳ね、敵の群れを崩していきます。経験値を集めてレベルが上がるたびに、8種類のスキルから強化を選べます。1画面で完結する、スマホでもPCでも遊べるアーケードです。

ベータ版です。最後まで遊べます。調整を続けているので、内容や演出が変わることがあります。

遊び方

  1. 弾を引く：マウスをドラッグして離すと、スリングショットで弾を発射します。ドラッグしている間は、時間がゆっくり（0.25倍）になるので狙いを定められます。
  2. 跳ね返す：敵の弾が来たら、Space か右クリックでパリィします。タイミングが合うと、弾を跳ね返して敵に当てられます。
  3. コンボをつなぐ：敵を倒すか、ジャストパリィを決めると、チェーンが伸びます。5回を超えると、スコア倍率が上がります。
  4. レベルアップで強化する：経験値が貯まるとレベルが上がり、3つのスキルから1つを選びます。
  5. コアを守る：敵の弾が当たるとコアの HP が減ります。HP が 0 になるとゲームオーバーです。

パリィのタイミング

敵の弾に合わせてパリィを押すと、タイミングの良さで効果が変わります。PERFECT と GREAT は、跳ね返した弾が敵を狙うホーミングになったり、衝撃波が出たりします。さらに、パリィのクールダウンがすぐに 0 秒にリセットされます。

判定タイミング効果
PERFECT0〜4フレーム弾の速さ 3.6 倍・威力 3.2 倍。敵へ直撃するホーミング。クールダウンが即時 0 秒
GREAT5〜9フレーム弾の速さ 2.4 倍・威力 2.0 倍。着弾で衝撃波が出る。クールダウンが即時 0 秒
GOOD10〜14フレーム弾の速さ 1.5 倍で反射。硬直がなく、続けて反撃できる

スコア倍率とバンクショット

  • チェーン 5〜9：COMBO SURGE（倍率 x2.0 から）
  • チェーン 10〜14：HYPER DRIVE（倍率 x3.0 から）
  • チェーン 15 以上：GODLIKE OVERDRIVE（倍率 x4.0 以上）
  • バンクショット：反射した弾や、突撃した敵を壁に跳ね返してから倒すと、x2.0〜x4.4 のボーナススコアが入ります。スキルの「トリックマスター」で、さらに倍率を上げられます。

スキル（強化）

レベルアップの画面では、3つのスキルから1つを選びます。1 から 3 のキーでも選べます。同じスキルを選ぶと、レベルが上がって強くなります。

敵とボス

  • スナイプオーブ：弾を一定の間隔で撃ってくる、基本の敵です。
  • ガトリングセンチネル：弾を撃ってくる敵です。
  • リフレクタープリズム：盾の角度の範囲で、弾を防ぐ敵です。
  • ボス：GRAVITY CORE：5 つめのウェーブに出るボスです。護衛として、プリズムとガトリングも一緒に出てきます。

ウェーブが進むと、戦場が広がります（3 つめのウェーブから）。ボスは、広くなった戦場で戦うことになります。

進め方のコツ

  • まずはパリィのタイミングに慣れる：PERFECT を狙うと、弾の威力も速さも大きく上がります。最初は GOOD でも、連続で反撃できます。
  • 壁を使う：壁で跳ね返すと、バンクショットの倍率が入ります。跳ね返す弾は、壁を通るように狙いましょう。
  • スキルは方向を決めて選ぶ：パリィ型なら「ジャストフレーム拡張」、爆発や電撃で押すなら「跳弾エクスプロージョン」や「テスラ放電オーラ」が向いています。
  • HP を見て強化を選ぶ：HP が減ってきたら「コア増強＆リペア」で全回復しましょう。
  • ボスは護衛から崩す：護衛のプリズムやガトリングを先に倒すと、ボスの弾が減ります。

作ったきっかけ

できることが少ないなかで遊ぶ、縛りプレイが好きです。「反射しかできないゲームは、どうだろう」というのが、Bullet Reflector の発想です。弾を撃って倒すのではなく、跳ね返すだけで戦います。

よくある質問

ゲームオーバーになったら、どうやって再開しますか？

Space・Enter・R のどれかで、すぐに最初からやり直せます。

スマホでも遊べますか？

はい。画面の左をドラッグして移動し、画面をドラッグして弾を撃ちます。右下の PARRY と DASH のボタンで、パリィとダッシュをします。

ハイスコアが消えてしまいました

ハイスコアは端末のブラウザ内にだけ保存されます。ブラウザのサイトデータを消すと、元に戻せません。

不具合を見つけました

ベータ版のため、まだ不具合が残っているかもしれません。お問い合わせから、使っている端末とブラウザ、起きたことを教えてください。
