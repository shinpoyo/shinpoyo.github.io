ALCHEMERGE: RAGNAROK

火・氷・雷の英霊を召喚して、同じ仲間どうしを合体させ、小さな幼体から神話の姿まで進化させながら、攻めてくる魔物から城を守るディフェンスゲームです。合体のたびに画面が光り、絵も攻撃の演出も別物に変わります。

開発中の作品です。最後まで遊べますが、内容や調整が変わったり、不具合が残っていたりすることがあります。

遊び方

  1. 召喚する：「召喚」ボタンか、空いている枠をタップすると、火・氷・雷のどれかの Lv.1 の幼体がランダムに出てきます。はじめは 30G を持っていて、1回 10G です（召喚するたびに 2G ずつ高くなり、45G が上限です）。
  2. 自動で戦う：英霊は自動で攻撃します。右から攻めてくる魔物のうち、いちばん城に近い敵を狙います。
  3. 合体する：同じ属性・同じレベルの英霊が2体いると、カードが光って「進化可」と出ます。そのカードをタップするか「進化合体」ボタンを押すと、1つ上のレベルに進化します。
  4. WAVE を守りきる：魔物を倒しきると WAVE クリア。3つの強化から1つ選んで、次の WAVE に進みます。
  5. 城を守る：魔物が城に着くとダメージを受けます。城の HP が 0 になるとゲームオーバーです。

盤は 4×3 の12枠です。全部埋まると召喚できなくなるので、合体して空けましょう。上の「⏩」で、ゲームの速さを2倍にできます。

合体と進化

合体するとレベルが1つ上がり、同時に画面全体の敵へ「進化衝撃波」が当たります。ダメージはレベルが高いほど大きくなります。

  • 飛び級進化：合体したとき、一定の確率で2つ上のレベルに一気に進化します（はじめは 24%。強化で上げられます）。
  • レベルが上がると：攻撃力は 2.25 倍ずつ強くなり、攻撃の間隔も短くなります。
  • 最大はレベル 7：イラストは Lv.5 で最終の姿になります。
  • 進化図鑑：進化させた姿は、画面上の「進化図鑑」に登録されます。まだ見ていない姿は暗く表示されます。

3つの属性

属性特徴
🔥 紅蓮（火）1発の威力がいちばん高い。Lv.3 以上では、当たった場所に炎の柱が立ちます。
❄️ 蒼氷（氷）当たった敵を、しばらくの間ゆっくりにします（動きが半分になります）。
⚡ 紫電（雷）連射が速い。Lv.2 以上では、近くにいる別の敵にも雷が連鎖します（最大3体、威力は7割）。

三属性共鳴：火・氷・雷の3つが盤にそろっていると、すべての英霊の攻撃力が 35% 上がります。

魔物と城

  • 1つの WAVE に出る魔物は 5 + WAVE数 × 2 体です。偶数の WAVE では、最後にボスが出ます。
  • 魔物は WAVE が進むほど硬く、速くなります。
  • 城に着いた魔物はそこで消え、城に 12 ダメージ（ボスは 30）を与えます。城の HP ははじめ 100 です。
  • 倒すと、ゴールドとスコアが手に入ります（魔物 10G、ボス 48G）。

奥義・強襲・強化

奥義

画面上の「奥義」ゲージが 100% になると、ボタンが光って使えるようになります。画面のあちこちに天罰の柱が降り注ぎ、広い範囲の敵に大ダメージを与えます。ゲージははじめ 50% で、合体で +30%、魔物を倒すと +9%（ボスは +36%）たまります。

強襲

「強襲」を押すと、次の WAVE の敵を前倒しで呼び出し、すぐに 25G もらえます。ゴールドが欲しいときの、リスクのある手段です。

WAVE クリアのときの強化

次の4つからランダムに3つが出て、1つ選べます。

強化効果

神速抜刀の境地全員の攻撃速度 +28%（ずっと続きます）

神引き飛び級＆奥義充填飛び級進化の確率 +12%、奥義ゲージが満タンに

進め方のコツ

  • まずは手持ちを合体：はじめから4体いて、同じ属性が2体います。すぐ合体できるので、最初の WAVE で進化を体験できます。
  • 3つの属性をそろえる：三属性共鳴で全員 +35% になります。合体で属性が減ってしまったら、足りない属性が出るまで召喚してみましょう。
  • 枠を空けておく：12枠が埋まると召喚できません。合体を後回しにしすぎないようにしましょう。
  • 奥義はボスに合わせて：ボスは偶数 WAVE の最後に出ます。ゲージが満タンなら、ボスが城に近づく前に使うと安心です。
  • 氷で時間をかせぐ：氷が当たった敵は遅くなります。火や雷の攻撃が当たる時間が、その分のびます。
  • 強襲は余裕のあるときだけ：城の HP が減っているときに押すと、一気に危なくなります。

画面

安心して遊べるように

  • ベストスコアと進化図鑑の記録は、端末の中だけに保存され、送信されません。
  • ゲームオーバーの画面の「戦績ポスト」は、押したときだけ X の投稿画面を開きます。投稿するかどうかは、その画面で自分で決められます。
  • ゲームの中の画像や効果音は、すべてゲームの中に入っていて、外部から読み込んでいません。

よくある質問

ゲームオーバーになったら、最初からですか？

はい。「再出撃」を押すと、WAVE 1 から始まります。ベストスコアと進化図鑑は残ります。

進化図鑑の絵が暗いままです

その姿にまだ進化させていないためです。合体で進化させると、図鑑に明るく登録されます。飛び級進化で通りすぎたレベルも、登録されます。

記録が消えてしまいました

記録は端末のブラウザ内にだけあるため、ブラウザのサイトデータを削除すると、元に戻せません。別の端末に引き継ぐこともできません。
