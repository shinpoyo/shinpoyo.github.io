「ニンニク」が「にんいく」になる理由 — ローマ字入力の「ん」の打ち方

タイピングゲーム「マシマシ打」でいちばん多いつまずきが、「ニンニク」を ninniku と打ってしまうことです。画面には「にんいく」と出てしまいます。原因は、ローマ字入力の「ん」の決まりにあります。

目次

なぜ「にんいく」になるのか

ローマ字入力では、n のあとに母音（a i u e o）が来ると「な・に・ぬ・ね・の」になります。そのため、n 1回だけでは、それが「ん」なのか「な行」の始まりなのか、次の文字を見るまで決まりません。

ninniku を前から順に読んでいくと、次のように区切られます。

入力なる文字
niに
nnん
iい
kuく

2つ目と3つ目の n が組になって「ん」になり、残った i が単独で「い」になってしまうわけです。「ニンニク」と出したいなら、「ん」のあとにもう一度「に」を打つ必要があるので、ninnniku（n が3つ）になります。

「ん」を n 1回で打てるとき・打てないとき

多くの日本語入力（IME）では、次のように考えると迷いません。

「ん」の次の文字「ん」の打ち方例
あ行（母音）nn が必要げんいん → genninn
な行nn が必要こんにちは → konnnitiha
や行・ゃゅょnn が必要こんや → konnya
それ以外の子音n 1回で OKさんぽ → sanpo
言葉の最後nn が確実ラーメン → ra-menn

言葉の最後の「ん」は、IME によっては n 1回でも変換時に「ん」になりますが、次の文字を続けて打つと別の文字とくっつくことがあります。迷ったら nn と覚えておくと安全です。

マシマシ打では、「ん」は nn と xn のどちらでも打てます。次の文字が母音・な行・や行以外なら n 1回でも進みます。

間違えやすい言葉の例

言葉よくある打ち間違い正しい打ち方の例
ニンニクninniku（にんいく）ninnniku
こんにちはkonnitiha（こんいちは）konnnitiha
きんようびkinyoubi（きにょうび）kinnyoubi
げんいんgenin（げにん）genninn
せんえんsenen（せねん）sennenn

迷わないためのコツ

  • 「ん」はいつも nn で打つ：慣れないうちは、次の文字に関係なく nn と打つ癖をつけると、打ち間違いがなくなります。打鍵数は少し増えますが、打ち直すより速くなります。
  • 慣れてきたら n 1回を使い分ける：「かんたん」「さんぽ」のように、次が子音で始まるときは n 1回で十分です。速さを求める段階になってから覚えれば大丈夫です。
  • 画面のかなを見る：打ち終わったあとではなく、打っている途中の表示を見ると、どこで区切られたかがすぐわかります。

「ニンニク」を打つ練習なら：マシマシ打では、店主の「ニンニク入れますか？」に、コールをローマ字で答えます。「ニンニク」が何度も出てくるので、nn の練習にちょうどいいはずです。
