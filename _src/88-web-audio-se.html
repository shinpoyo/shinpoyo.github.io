音声ファイルなしで効果音を鳴らす — Web Audio API の基本

このサイトのゲームのいくつかは、効果音に音声ファイルを使っていません。ブラウザに入っている Web Audio API で、その場で音を作って鳴らしています。この記事では、そのいちばん基本の作り方を紹介します。

ファイルを使わない良さ

  • 読み込みがいらない：音声ファイルをダウンロードしないので、ページがすぐに使えます。
  • 容量がほぼゼロ：音はコードの数行です。ゲームを1つのファイルにまとめやすくなります。
  • 変化をつけやすい：音の高さを少しずつ変えるなど、場面に合わせた調整がコードだけでできます。

一方で、人の声や楽器のような複雑な音は苦手です。「ピッ」「コン」「ドーン」のような、短くて単純な効果音に向いています。

いちばん小さなコード

Web Audio API では、音を作る部品（ノード）をつないで音を鳴らします。いちばん簡単なのは、一定の高さの音を出す「オシレーター」と、音量を決める「ゲイン」をつなぐ形です。

const ctx = new AudioContext();

function beep() {
  const osc = ctx.createOscillator();   // 音を出す
  const gain = ctx.createGain();        // 音量を決める
  osc.frequency.value = 880;            // 音の高さ（Hz）
  gain.gain.value = 0.2;                // 音量（0〜1）
  osc.connect(gain);
  gain.connect(ctx.destination);        // スピーカーへ
  osc.start();
  osc.stop(ctx.currentTime + 0.1);      // 0.1秒で止める
}

これで「ピッ」と鳴ります。ただ、このままだと音の始まりと終わりがぶつっと切れて、少し機械的に聞こえます。

音程と音量を動かして「効果音」にする

効果音らしくするコツは、短い時間のうちに音の高さと音量を変化させることです。たとえば「ねーちゃんとオセロ」で石を置いたときの音は、次のように作っています。

function place() {
  const now = ctx.currentTime;
  const osc = ctx.createOscillator();
  const gain = ctx.createGain();
  osc.type = 'triangle';
  // 340Hz から 65Hz へ、0.065秒で一気に下げる
  osc.frequency.setValueAtTime(340, now);
  osc.frequency.exponentialRampToValueAtTime(65, now + 0.065);
  // 音量も 0.07秒でほぼゼロまで下げる
  gain.gain.setValueAtTime(0.45, now);
  gain.gain.exponentialRampToValueAtTime(0.001, now + 0.07);
  osc.connect(gain);
  gain.connect(ctx.destination);
  osc.start(now);
  osc.stop(now + 0.075);
}

高い音から低い音へ素早く下げると、「コン」という、ものを置いたような音になります。反対に、低い音から高い音へ上げると「ピコッ」と明るい音になります。

  • 下がる音：置く・当たる・落ちる
  • 上がる音：決定・ひらめき・アイテム入手
  • 音を少しずつ高くする：連続で何かが起きるとき（たとえば石を何枚もひっくり返すとき）に、1つごとに音を高くすると、気持ちよく盛り上がります。

さらに、いくつかのオシレーターを重ねて和音にしたり、ノイズ（ランダムな波）を作ってフィルターをかけたりすると、爆発や崩れる音のような、にぎやかな音も作れます。

波形のちがい

オシレーターの type を変えると、音の感じが変わります。

type音の感じ向いている音
sineやわらかく、丸いポップな決定音、心臓の音
trianglesine より少しはっきり石を置く音、メロディ
squareレトロゲームのような、ピコピコした音8ビット風の効果音
sawtoothジリジリした、強い音警告、衝撃、ボスの攻撃

つまずきやすいところ

  • 最初の操作まで音が鳴らない：多くのブラウザは、ページを開いただけで勝手に音が鳴らないようにしています。AudioContext は止まった状態（suspended）で始まることがあるので、ボタンを押したときなど、利用者の操作のあとで ctx.resume() を呼びましょう。
  • 音量を 0 まで「なめらかに」下げられない：exponentialRampToValueAtTime は、目標の値に 0 を指定できません。0.001 のような、とても小さい値を使います。
  • 止めるのを忘れない：stop() を呼ばないオシレーターは鳴り続けます。音量を下げきったあと、少し後に止めるようにしましょう。
  • 音量は控えめに：重ねるほど音は大きくなります。1つの音のゲインは 0.2〜0.5 くらいから試し、消音ボタンも用意しておくと親切です。

この記事のような効果音は、このサイトの作品で実際に使っています。音のON/OFFを切り替えながら、遊んで聞きくらべてみてください。
