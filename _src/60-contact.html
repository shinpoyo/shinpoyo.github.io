お問い合わせ

作品の不具合のご報告、ご意見・ご感想、そのほかのご連絡は、次の方法でお願いします。

連絡先

GitHub
github.com/shinpoyo

マシマシ打の不具合は、マシマシ打のリポジトリの Issues に書き込んでいただくのが一番早く確認できます（GitHub のアカウントが必要です）。

不具合を報告していただくとき

次のことを書いていただけると、原因を調べやすくなります。

  • 作品の名前
  • 使っている端末とブラウザ（例：Windows の Chrome、iPhone の Safari）
  • どんな操作をしたときに、どうなったか
  • 可能であれば画面のスクリーンショット

ご注意

  • 個人で運営しているため、お返事にお時間をいただくことや、お返事できない場合があります。
  • パスワードなど、他の人に見られて困る情報は書き込まないでください（Issues は公開されます）。
